# CRM для автосервиса

Система автоматизации для СТО. Позволяет вести базу заявок, распределять задачи между мастерами и отказаться от бумажных журналов.

## Стек
* Python (Flask)
* SQLite
* HTML/CSS/JS
* SMS-шлюз для уведомлений

## Запуск
1. Установите зависимости: `pip install -r requirements.txt`
2. Запустите: `python run.py`
